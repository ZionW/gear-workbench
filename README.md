# 齒輪工坊 · Gear Workbench

在瀏覽器中建立齒輪、配置多零件連動，並匯出 CAD 幾何。不需安裝、登入或連接 Codex。

網站：https://zionw.github.io/gear-workbench/

## 功能

- 直齒外齒輪、斜齒外齒輪、內齒輪與齒條。
- 最多 12 個零件；設定 X / Y / Z、齒條方向、初相與固定條件。
- 拖曳配置、自動對位、齒面嚙合或同軸剛接。
- 指定主動零件與轉速／線速，播放、暫停、回到起點或單步模擬。
- 檢查模數、壓力角、旋向、中心距、軸向重疊、固定條件及閉合迴路。
- 齒條超過有效行程會停止；不會視為無限長齒條。
- 複製 SVG、一次複製全部零件的 Rhino 3D 命令，下載 STL、STEP、DXF。
- 參數、位置、模擬、連動及匯出區塊可折疊，瀏覽器會記住開合狀態。
- 可匯出選取零件或整組配置；整組 STEP 保留各自的實體。

## 使用

1. 選擇範例，再按「載入範例」，或新增自己的零件。
2. 在左側設定齒形與位置。模數支援 1.25 等小數；斜齒輪輸入的是法向模數。
3. 在「連動關係」選擇兩個零件，按「對位並連動」。
4. 指定主動零件與轉速，再按「開始運轉」。
5. 選擇單顆或整組，複製或下載目前姿態的幾何。

尺寸使用 **mm**。STL 沒有原生單位，匯入切片軟體時請選 mm。SVG 與 DXF 是 XY 平面投影。剪貼簿是否能直接貼上向量，取決於瀏覽器及接收軟體；SVG 不會顯示原始碼欄位。Rhino 複製使用自含的 `_-RunPythonScript` 命令（Rhino 內建 Python，無需外掛、下載或暫存檔），直接由輪廓的 NURBS 控制點建立平面區域、開口擠出、組合底面與側面，再用 `CapPlanarHoles` 加蓋並保留軸孔。全部零件先通過有效性與封閉實體檢查後，才加入文件；不會留下輪廓物件或執行 `Check` / `What` 視窗。每次貼上皆使用新的圖層識別，支援重複貼上，不以圖層選取、目前工作平面或互動指令預設值決定幾何。Rhino 固定包含整組齒輪，不受 SVG／下載範圍影響，並將毫米自動換算為接收文件單位。已在 Rhino 8 繁中 Mac／公分文件透過實際 `Paste` 流程驗證直齒、左右旋斜齒、內齒輪、齒條及無軸孔模型：各一個有效封閉實體，3–4 個曲面。尚未驗證製造精度或完整齒面干涉。

配置儲存在此瀏覽器的 localStorage。計算及匯出均在瀏覽器執行；程式沒有分析追蹤或資料上傳。GitHub Pages 仍會接收一般網站請求。清除網站資料會移除配置。

## 模型範圍

此工具是固定輪心、平行軸的**理想運動學**工具，尚未建立行星架運動、負載、摩擦、彈性、背隙、強度或完整的齒面接觸／碰撞分析。

齒根與齒形採平滑幾何近似；「速比與位置條件通過」不等於可直接製造或保證無干涉。尤其內齒輪仍需檢查漸開線、次擺線及切削干涉。代表性輸出已使用 Open CASCADE 重新讀取檢查，四種範例的 STEP 為有效封閉實體，STL 為封閉網格，DXF 格式檢查無錯誤；並非所有可能參數均完成驗證。

幾何參考：[KHK 齒輪尺寸計算](https://khkgears.net/new/gear_knowledge/gear_technical_reference/calculation_gear_dimensions.html)。不宣稱取得 ISO 精度等級或標準符合性認證。

## 本機開發

本專案是無建置步驟的靜態網站，無第三方執行期依賴。

```sh
python3 -m http.server 8000
```

開啟 `http://localhost:8000`。使用 localhost 或 HTTPS，瀏覽器才能提供剪貼簿功能。

```sh
node --test
```

- `assets/engine.js`：齒形、尺寸與連動求解。
- `assets/exports.js`：SVG、DXF、STL、STEP 及 Rhino 命令。
- `assets/app.js`：配置介面、模擬、localStorage 與下載。
- `assets/styles.css`：響應式樣式與明暗外觀。

## 本機新版操作

- 預設「基本版」集中尺寸、2D／3D 預覽、運轉與輸出；「進階版」開放座標、壓力角、齒相、驅動與手動連動。版本選擇與吸附開關會保存在瀏覽器。
- 開啟「自動吸附連動」，在 2D 將齒輪拖近後放開，系統會在約 12 螢幕像素或 1.5 倍模數的範圍內，將節圓／節線對位並建立連動及自動對齒。移動可用「復原配置」撤銷。
- 支援直齒、相反旋向的平行軸斜齒、內外齒及齒條。模數、壓力角、Z 重疊、既有連動及閉合迴路均需通過檢查；固定零件與同軸剛接零件不自動吸附。不相容或距離太遠時保留拖曳位置，不強制改動尺寸或刪除既有連動。
- 桌面基本版將主要操作集中於單頁；進階版的設定與連動區可個別捲動。手機以預覽為先，設定在下方。

## 凹槽洞洞板與可拔插支撐桿（本機新版）

展開「底盤與支撐桿」，開啟「生成列印底盤」。板面為規則孔陣列，每孔帶錐形沉槽；支撐桿由插腳、定位座、承托肩與轉軸組成，可拔出換孔，齒輪可向上取下（未含上方防脫蓋）。預設孔距 10 mm、板厚 6 mm、插腳直徑 6 mm、沉槽深 1.5 mm、齒輪離板 4 mm，板面依齒輪外形加 10 mm 餘量自動延伸。

- 「底盤 STL」輸出一件封閉孔板；「支撐桿 STL」依各輪軸孔及齒寬生成桿件，分件排開並落在 Z=0。齒輪由原有 STL 按鈕另行下載。底盤及桿件提供 STL，也可用「複製底盤至 Rhino」建立獨立的封閉實體；主區的 STEP／DXF 按鈕仍針對齒輪。
- 預設 **0.3 mm 為直徑差**：孔徑＝插腳直徑＋間隙，轉軸直徑＝齒輪軸孔－間隙。此為可調初值，尚未實體試印，需先確認所用印表機與材料的配合。
- 輪心需落在規則孔位。「對齊孔位」只在不破壞既有連動時才移動輪心，否則保留位置並提示調整孔距；未對孔時不能輸出誤導的桿件。
- 本版桿件支援有至少 3 mm 軸孔的直齒及斜齒外齒輪；內齒輪與齒條需要另外的環形支撐或線性滑軌，介面會明示。
- 2D 拖曳齒輪進入有效吸附範圍時，外緣顯示黃色實線，吸附後輪廓顯示黃色虛線；移出範圍、放開或取消拖曳會清除提示，預覽不會提早建立連動。

### 底盤複製至 Rhino

在「底盤與支撐桿」開啟生成列印底盤，按「複製底盤至 Rhino」。預設勾選「包含可拔插支撐桿」，取消後可只複製底盤；選項會保存在瀏覽器。貼至 Rhino 8 命令列後，會以平滑圓孔、錐形沉槽及旋轉桿件建立封閉 BRep，不以 STL 三角網格代替。保留板面、輪心與桿件的組裝位置，並按接收文件單位換算毫米。未對孔位時仍可取消桿件選項、只複製底盤。所有實體先驗證再加入文件，支援重複貼上與復原，不保留輔助輪廓。

## 選取齒輪的浮動參數

在 2D 或 3D 點一下齒輪，或由「目前零件」選單選取，即會顯示可直接編輯的浮動參數；也可用預覽上方「參數」按鈕開關。基本欄位包含模數、齒數、齒寬及適用的軸孔／螺旋角／環壁／齒條背厚；進階版另提供壓力角與 X/Y。面板與左側設定使用同一份資料，可用復原配置撤銷參數變更。無效輸入會在面板提示並保留原模型。

桌面面板會依齒輪位置選擇鄰近方向並限制在預覽範圍；手機改為底部浮動面板。拖曳零件或旋轉視角時暫時隱藏，放開後跟隨；開始運轉時也會隱藏，點選齒輪會暫停供編輯。可按 × 或 Esc 關閉，或由「完整設定」前往左側。點選選取不會新增復原紀錄，真正拖動後才記錄一次編輯。

### A1 PLA 列印間隙與整組 Rhino 複製

本機介面提供 A1／PLA／0.4 mm 噴嘴、0.20 mm 層高的可調試印起始配置。齒側間隙預設一對合計 0.20 mm，每輪沿節圓減少 0.10 mm 齒厚；內齒輪與齒條也採去除材料的方向。不縮放模型、不改模數、節徑、中心距或速比。預覽與 SVG、DXF、STL、STEP、Rhino 使用相同齒形。齒側設 0 可還原原齒厚；小模數或過薄齒頂會拒絕超量補償。

支撐桿旋轉配合與底盤插拔配合分開設定，預設均為直徑差 0.30 mm（單側 0.15 mm）。軸孔維持輸入直徑，桿徑由旋轉配合減小；底盤孔由插腳直徑加插拔配合。舊配置的 clearance 會遷移為同值旋轉配合，之後兩者可獨立調整。以上不是原廠保證公差，請先試印並依材料、切片與實測調整；切片孔徑補償避免重複計入，象腳由切片設定處理。

「複製整組 3D 至 Rhino」一次建立所有齒輪，以及勾選的已啟用底盤與支撐桿，沿用單次原子式實體驗證；不保留輔助曲線。未對孔位時須先對齊或取消桿件。複製保留組裝位置，列印前需分件擺放；STL 的底盤／桿件獨立下載仍可使用。底盤超過 A1 的 256 × 256 mm 成形面時顯示提示。

參考：[A1 官方規格](https://bambulab.com/en/a1/tech-specs)、[Bambu Studio 官方 A1 0.4 mm 預設](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/Bambu%20Lab%20A1%200.4%20nozzle.json)、[XY 孔與輪廓補償](https://wiki.bambulab.com/en/software/bambu-studio/xy-hole-contour-compensation)。

### 統一下載

「複製與下載」集中所有下載入口，可選整套列印包、選取齒輪、全部齒輪、底盤或支撐桿。齒輪支援 STL／STEP／DXF；底盤與桿件提供 STL，切換內容時自動限制格式。下載選擇與 SVG 範圍獨立，並記住下載偏好。

整套列印包為單一 ZIP（標準 store 格式，含 CRC32 與 UTF-8 檔名），每個齒輪為獨立 STL，並包含已啟用底盤、可用桿件與 README 組裝位置／間隙說明。各齒輪、底盤與桿件 STL 底面移至 Z=0；請於切片器排版後分件列印。包含桿件時若輪心未對孔位，整包會先拒絕輸出；底盤仍可獨立下載。未啟用底盤時整包只包含齒輪。全部齒輪的單檔 STL／STEP 保留原組裝位置，DXF 輸出 XY 投影。

### 參數變更自動對位與省料凹槽

在側欄或浮動參數修改齒數、模數、壓力角、螺旋角或厚度後，已連接的機構會依原方位重新計算中心距。同一嚙合網路的模數／壓力角會同步，斜齒輪維持相反旋向；複合軸的上下順序及軸向間隔會保留。不相容齒型、無法成立的閉環或固定限制會拒絕變更並保留原配置。一次參數變更及連動對位可一起復原。輪心重新對位後，底盤桿件仍須確認規則孔位，避免移動至網格破壞正確嚙合中心距。

原「齒寬」欄位明確標示為「齒輪厚度」。直齒與斜齒外齒輪可開啟正面（+Z）環形省料凹槽，調整深度、輪緣及軸心保留厚度。凹槽底厚至少 1.2 mm，輪緣／軸心保留至少 1.2 mm，凹槽寬至少 1 mm；這些是幾何下限，並非負載強度驗證。預覽、STL、列印包、STEP 與 Rhino 複製同步輸出實際凹槽；SVG／DXF 仍為外輪廓與軸孔投影，不輸出凹槽加工線。內齒輪與齒條目前不提供此環形凹槽。

凹槽 STL 使用封閉、有方向的網格，STEP 使用平面與圓柱面，Rhino 使用解析曲面布林去料並在加入文件前驗證封閉性。Rhino 原生貼上與 STEP 匯入已比對直齒、斜齒及無軸孔版本的去料體積；STL 亦驗證網格封閉及去料量。

3D 預覽加入底部外輪廓與齒側轉折邊線，斜齒輪邊線沿扭轉方向繪製。軸孔及凹槽邊線裁切於可見開口，避免隱藏線穿透外壁；深淺主題均有對應線色。此為預覽顯示調整，不改匯出模型。
